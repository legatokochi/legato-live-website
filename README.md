LEGATO LIVE — WEBSITE PREVIEW (PACKAGES EDITION)
============================================

Start here
----------
1. Extract the ZIP file.
2. Open the extracted Legato-Live-Website-Production-Bookings-Edition folder.
3. In File Explorer, click the address bar, type cmd, then press Enter.
4. Run: py -m http.server 8000
5. Visit http://localhost:8000 in your browser.
6. If the browser shows an older site, press Ctrl + F5.

If port 8000 is already in use, stop the earlier Command Prompt server using Ctrl + C,
or run `py -m http.server 8001` and open http://localhost:8001 instead.
